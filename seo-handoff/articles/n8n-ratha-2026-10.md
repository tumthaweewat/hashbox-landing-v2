## Execution คืออะไร และทำไมมันกำหนดราคาที่คุณจ่าย

**Execution คือ** การรัน workflow หนึ่งครั้งตั้งแต่ต้นจนจบ — n8n นับเป็น 1 execution ไม่ว่า workflow นั้นจะมี 3 ขั้นตอนหรือ 30 ขั้นตอน (หน้าราคาของ n8n เขียนไว้ว่าคิดเงินตาม "การรันเต็มรอบ ไม่ใช่ทีละขั้นตอน")

สูตรประมาณการ:

**Executions ต่อเดือน = (จำนวนรอบที่ตั้งเวลาไว้ต่อวัน × 30) + จำนวนเหตุการณ์ที่เข้ามาทาง webhook ต่อเดือน**

| workflow ของคุณ | Executions / เดือน | แผนที่พอ |
|---|---|---|
| รันวันละครั้ง (สรุปรายงานเช้า) | ~30 | Starter เหลือเฟือ |
| รันทุกชั่วโมง | ~720 | Starter |
| **รันทุก 15 นาที** | **~2,880** | **เกิน Starter (2,500) → Pro** |
| รันทุก 5 นาที | ~8,640 | Pro (10,000) |
| ออร์เดอร์เข้า 100 รายการ/วัน ผ่าน webhook | ~3,000 | Pro |
| 5 workflow แต่ละตัวรันทุก 15 นาที | ~14,400 | Pro แบบขยาย หรือติดตั้งเอง |

**กับดักที่เจอบ่อย:** คนตั้งงานเช็กข้อมูล "ทุก 15 นาที" เพราะฟังดูไม่ถี่ แต่ 15 นาทีคือเกือบ 3,000 รอบต่อเดือนต่อ workflow เดียว — ถ้ามีงานแบบนี้หลายตัว ให้ถามก่อนว่า**ต้องถี่ขนาดนั้นจริงไหม** การเปลี่ยนเป็นทุกชั่วโมงลดรอบลง 4 เท่า หรือเปลี่ยนจาก "เช็กตามเวลา" เป็น "ให้ระบบต้นทางส่ง webhook มาเมื่อมีของใหม่" มักลดได้มากกว่านั้น

## ติดตั้งเองฟรีจริงไหม — ต้นทุนที่ไม่อยู่ในตารางราคา

Community Edition ไม่มีค่าไลเซนส์ และไม่จำกัดจำนวน execution ด้วยแผน — แต่ "ฟรี" หมายถึงค่าไลเซนส์เท่านั้น สิ่งที่คุณจ่ายแทน:

| ต้นทุน | คืออะไร | ใครมักลืม |
|---|---|---|
| เซิร์ฟเวอร์ | VPS หรือเครื่องในบริษัทที่เปิดทิ้งไว้ตลอด | ธุรกิจที่ใช้โฮสต์แชร์ราคาถูก ซึ่งมักไม่ให้ process ค้างไว้ |
| เวลาคนดูแล | อัปเดตเวอร์ชัน แก้ตอนเครื่องล่ม ดู log | ทุกคน — เป็นต้นทุนที่ใหญ่ที่สุดและไม่มีใบแจ้งหนี้ |
| สำรองข้อมูล | workflow + credentials + ประวัติการรัน | คนที่เพิ่งรู้ตอนเครื่องพัง |
| ความปลอดภัย | HTTPS, รหัสผ่าน, การเปิดพอร์ต, เก็บ API key | คนที่เปิดหน้าแอดมินให้ทั้งอินเทอร์เน็ตเข้าถึงได้ |
| ฟีเจอร์ระดับทีม | SSO, Git version control, หลาย environment | ทีมที่โตขึ้นแล้วต้องจ่าย Business ทีหลัง |

นอกจากนี้ Community Edition ใช้ไลเซนส์แบบ fair-code (Sustainable Use License) — ใช้ภายในธุรกิจของคุณเองได้ แต่มีเงื่อนไขเรื่องการนำ n8n ไปให้บริการต่อ ถ้าคุณจะเอา n8n ไปเป็นส่วนหนึ่งของบริการที่ขายให้ลูกค้า ให้อ่านเงื่อนไขไลเซนส์ก่อน

**ตัดสินใจง่ายๆ:** ถ้าในทีมไม่มีใครดูแลเซิร์ฟเวอร์ได้ และงานไม่ถึง 10,000 executions/เดือน **Cloud Pro (~1,890–2,270 บาท/เดือน) มักถูกกว่าเวลาคนที่ต้องเสียไปกับการดูแลเครื่องเอง** · ถ้ามีคนดูแลเครื่องอยู่แล้ว หรือข้อมูลห้ามออกนอกบริษัท ติดตั้งเองคุ้มกว่า

## ค่า AI ไม่รวมในราคา n8n

workflow ที่ใช้ AI (สรุปข้อความ ตอบแชต จัดหมวดเอกสาร) จ่ายสองก้อนแยกกัน:

1. **ค่า n8n** — ตามแผนด้านบน
2. **ค่าโมเดล AI** — จ่ายให้ผู้ให้บริการโมเดลตามจำนวนที่ใช้ (โดยมากคิดตามปริมาณข้อความ) ไม่ว่าคุณจะใช้ n8n แผนไหน

แผน Starter และ Pro มีตัวเลือกใช้โมเดล AI ผ่านเครดิตแบบเติมเงินล่วงหน้ากับ n8n โดยไม่ต้องมี API key ของตัวเอง — สะดวกตอนเริ่ม แต่ก็ยังเป็นเงินแยกจากค่าแผน **ก่อนเปิดใช้ workflow AI ที่รันถี่ ให้ประเมินค่าโมเดลต่อรอบคูณจำนวนรอบต่อเดือนก่อนเสมอ** — มันมักแพงกว่าค่า n8n เอง

## FAQ: คำถามที่พบบ่อยเรื่องราคา n8n

**n8n ฟรีไหม?**
ฟรีถ้าติดตั้งเองบนเซิร์ฟเวอร์ของคุณ (Community Edition) ไม่มีค่าไลเซนส์และไม่จำกัด execution ด้วยแผน แต่คุณจ่ายค่าเซิร์ฟเวอร์และเวลาคนดูแลเอง ถ้าใช้บนคลาวด์ของ n8n มีแผน Free สำหรับทดลอง และแผนเสียเงินเริ่มที่ €24 ต่อเดือน (ประมาณ 910 บาท ณ ต.ค. 2026)

**n8n Cloud ราคาเท่าไหร่?**
ณ 6 ต.ค. 2026: Starter €24/เดือน (2,500 executions) · Pro €60/เดือน (10,000 executions) · ถ้าจ่ายรายปีเหลือ €20 และ €50 ต่อเดือนตามลำดับ คิดเป็นเงินบาทประมาณ 760–2,270 บาทต่อเดือน ราคาเปลี่ยนได้ ให้ตรวจที่หน้าราคาของ n8n ในวันที่ตัดสินใจ

**Execution ของ n8n นับยังไง?**
นับหนึ่งครั้งต่อการรัน workflow หนึ่งรอบ ไม่ว่า workflow จะมีกี่ขั้นตอน คำนวณคร่าวๆ ได้จากจำนวนรอบที่ตั้งเวลาไว้ต่อวันคูณ 30 บวกจำนวนเหตุการณ์ที่เข้ามาทาง webhook ต่อเดือน เช่น workflow ที่รันทุก 15 นาทีใช้ประมาณ 2,880 executions ต่อเดือน

**ติดตั้ง n8n เอง (self-hosted) ต้องจ่ายอะไรบ้าง?**
ค่าเซิร์ฟเวอร์ที่เปิดทิ้งไว้ตลอด เวลาคนดูแลอัปเดตและแก้ปัญหา ระบบสำรองข้อมูล และการตั้งค่าความปลอดภัย ไม่มีค่าไลเซนส์ ถ้าต้องการฟีเจอร์ระดับทีมอย่าง SSO หรือ Git version control ต้องจ่ายแผน Business เพิ่ม

**จ่ายรายปีถูกกว่ารายเดือนเท่าไหร่?**
ประมาณ 17% สำหรับแผน Starter และ Pro (€24 → €20 และ €60 → €50 ต่อเดือน) คุ้มเมื่อมั่นใจแล้วว่าจะใช้ต่อเนื่องทั้งปี ช่วงแรกที่ยังไม่แน่ใจปริมาณงาน จ่ายรายเดือนยืดหยุ่นกว่า

**ใช้เกินจำนวน execution ของแผนแล้วเกิดอะไรขึ้น?**
หน้าราคาของ n8n ระบุค่าส่วนเกินของแผน Business ไว้ที่ 4,000 ยูโรต่อ 300,000 executions ส่วนแผนอื่นให้ดูเงื่อนไขล่าสุดที่หน้าราคา ทางที่ดีกว่าคือคำนวณจำนวนรันก่อนเลือกแผน และลดรอบที่ไม่จำเป็น เช่น เปลี่ยนจากเช็กทุก 15 นาทีเป็นรับ webhook

**ค่า AI รวมอยู่ในราคา n8n ไหม?**
ไม่รวม ค่าโมเดล AI จ่ายแยกตามปริมาณที่ใช้ แผน Starter และ Pro มีตัวเลือกใช้โมเดลผ่านเครดิตแบบเติมเงินล่วงหน้ากับ n8n แต่ยังเป็นเงินแยกจากค่าแผน workflow AI ที่รันถี่ ค่าโมเดลมักแพงกว่าค่า n8n เอง

**จ้างวางระบบ n8n ราคาเท่าไหร่?**
บริการวางระบบ n8n ของ Hashbox เริ่มต้น 29,000 บาทต่อโปรเจกต์ ไม่รวม VAT 7% คิดเป็นโปรเจกต์ไม่ใช่รายเดือน ติดตั้งบนเซิร์ฟเวอร์ของคุณเองและส่งมอบไฟล์ workflow พร้อมเอกสาร ราคาจริงขึ้นกับจำนวน workflow และจำนวนระบบที่ต้องเชื่อม
