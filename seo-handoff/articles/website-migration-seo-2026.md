# ทำเว็บใหม่แล้วอันดับหาย แก้ยังไง

**สาเหตุอันดับหนึ่งคือ URL เปลี่ยนโดยไม่ได้ตั้ง redirect ทำให้ทุกหน้าที่เคยติดอันดับกลายเป็นหน้าไม่พบ และ Google ถอดหน้าเหล่านั้นออกจากผลค้นหาภายในไม่กี่สัปดาห์ วิธีตรวจใช้เวลาไม่ถึงสิบนาที คือเปิด Search Console ดูรายงานหน้าที่ถูกจัดทำดัชนี แล้วเทียบกับรายการ URL เดิม ถ้าเจอหน้าที่เคยมีคนเข้ากลายเป็นสถานะไม่พบ นั่นคือสาเหตุ และแก้ได้ด้วยการตั้ง redirect 301 จาก URL เดิมไปหน้าใหม่ที่เนื้อหาตรงกันมากที่สุด**

บทความนี้เขียนสำหรับคนที่เพิ่งย้ายเว็บหรือเปลี่ยนธีมแล้วเห็นตัวเลขตก และต้องการรู้ว่าเกิดอะไรขึ้นและแก้อย่างไร เรียงตามลำดับที่ควรตรวจ จากสาเหตุที่พบบ่อยที่สุดไปหาที่พบน้อยที่สุด

ก่อนอื่นต้องแยกให้ออกสองอย่าง อันดับตกจริง กับอันดับตกชั่วคราวตามธรรมชาติ หน้าที่เพิ่งถูกจัดทำดัชนีใหม่มักผันผวนในช่วงสองถึงสี่สัปดาห์แรก ถ้าคุณเพิ่งย้ายเว็บได้ไม่ถึงสองสัปดาห์และตัวเลขยังไม่ดิ่ง ให้รอดูก่อนและตรวจตามลำดับด้านล่างไปพร้อมกัน

## ตรวจสาเหตุตามลำดับนี้

### สาเหตุที่ 1 ไม่ได้ตั้ง redirect หรือตั้งไม่ครบ

เกิดขึ้นเมื่อโครงสร้าง URL เปลี่ยน เช่น จาก บริการ เป็น services หรือจากลิงก์ที่มีรหัสตัวเลขเป็นลิงก์ที่เป็นชื่อ

**วิธีตรวจ** เข้า Search Console เลือกรายงานหน้าเว็บ ดูหมวดที่ไม่ได้จัดทำดัชนี ถ้าเห็นจำนวนหน้าไม่พบเพิ่มขึ้นชัดเจนหลังวันย้ายเว็บ นี่คือสาเหตุ อีกวิธีที่เร็วกว่าคือเปิด URL เก่าที่คุณจำได้สามถึงห้าอันในเบราว์เซอร์

**วิธีแก้** ตั้ง redirect 301 จากทุก URL เดิมไปยังหน้าใหม่ที่เนื้อหาใกล้เคียงที่สุด หลักการสำคัญคือชี้ไปหน้าที่เนื้อหาตรงกัน ไม่ใช่ชี้ทุกหน้าไปหน้าแรก การชี้ทุกอย่างไปหน้าแรกให้ผลเกือบเท่ากับไม่ทำ เพราะระบบมองว่าเนื้อหาเดิมหายไปแล้ว

ถ้าใช้ WordPress ทำได้ผ่านปลั๊กอินจัดการ redirect หรือตั้งที่ระดับเซิร์ฟเวอร์ ซึ่งเร็วกว่า แต่ต้องเข้าถึงไฟล์ตั้งค่าได้

### สาเหตุที่ 2 หน้าใหม่ถูกตั้งไม่ให้ระบบเก็บ

เกิดจากตอนพัฒนาเว็บมีการตั้งค่าไม่ให้เสิร์ชเอนจินเก็บข้อมูล เพื่อไม่ให้เว็บที่ยังไม่เสร็จขึ้นในผลค้นหา แล้วลืมปลดตอนเปิดใช้จริง

**วิธีตรวจ** ใน WordPress เข้าที่ตั้งค่าแล้วเลือกการอ่าน ดูว่าช่องห้ามเสิร์ชเอนจินทำดัชนีถูกติ๊กอยู่หรือไม่ อีกทางคือเปิด yourdomain.com/robots.txt แล้วดูว่ามีบรรทัดห้ามเก็บทั้งเว็บอยู่หรือไม่

**วิธีแก้** ปลดการตั้งค่านั้น แล้วขอให้ Google เก็บหน้าใหม่ผ่านเครื่องมือตรวจสอบ URL ใน Search Console

ข้อนี้ฟังดูพื้นฐานมากแต่เป็นสาเหตุที่เราเจอบ่อยเป็นอันดับสอง และเป็นข้อที่แก้แล้วเห็นผลเร็วที่สุดในบรรดาทั้งหมด

### สาเหตุที่ 3 เนื้อหาหายไปจริง

เว็บใหม่ที่ออกแบบสวยขึ้นมักมีข้อความน้อยลง หน้าที่เคยมีคำอธิบายยาวกลายเป็นหน้าที่มีแต่ภาพกับหัวข้อสั้น ๆ เมื่อเนื้อหาที่เคยทำให้หน้านั้นตรงกับคำค้นหายไป อันดับก็หายตาม

**วิธีตรวจ** เปิดหน้าเก่าจากแคชหรือจากเว็บอาร์ไคฟ์ แล้วเทียบกับหน้าใหม่ นับคร่าว ๆ ว่าข้อความหายไปเท่าไหร่ และหัวข้อที่เคยมีอยู่ยังอยู่ครบไหม

**วิธีแก้** เอาเนื้อหาที่หายกลับมา ไม่จำเป็นต้องวางแบบเดิม จัดใหม่ให้อ่านง่ายได้ แต่ประเด็นที่เคยครอบคลุมต้องยังอยู่

### สาเหตุที่ 4 โครงหัวข้อเปลี่ยนไป

ธีมใหม่บางตัวใช้หัวข้อระดับ H1 กับชื่อเว็บทุกหน้า หรือข้ามลำดับหัวข้อ ทำให้ระบบอ่านไม่ออกว่าหน้านั้นเกี่ยวกับอะไร

**วิธีตรวจ** คลิกขวาที่หน้าเว็บแล้วเลือกดูซอร์สโค้ด ค้นหาคำว่า h1 ควรมีหนึ่งอันต่อหน้า และควรเป็นหัวข้อของหน้านั้น ไม่ใช่ชื่อบริษัท

**วิธีแก้** แก้ที่ธีมหรือที่การตั้งค่าหัวข้อของหน้า ถ้าแก้เองไม่ได้ต้องให้ผู้พัฒนาแก้

### สาเหตุที่ 5 ความเร็วเว็บแย่ลง

เว็บใหม่ที่ใส่ภาพความละเอียดสูงและแอนิเมชันเยอะ มักโหลดช้ากว่าเว็บเดิม ความเร็วไม่ใช่ปัจจัยที่ทำให้อันดับดิ่งเพียงลำพัง แต่ซ้ำเติมเมื่อมีปัญหาอื่นอยู่แล้ว

**วิธีตรวจ** ใช้ PageSpeed Insights ของ Google ดูค่า Core Web Vitals

**วิธีแก้** เริ่มจากบีบอัดภาพและตั้งให้ภาพที่อยู่นอกจอโหลดทีหลัง สองอย่างนี้แก้ปัญหาได้เกินครึ่งของกรณีที่เจอ รายละเอียดเพิ่มเติมอยู่ใน[คู่มือแก้ LCP](https://hashbox.co.th/lcp-คืออะไร-วิธี-2026/)

### สาเหตุที่ 6 structured data หายไปพร้อมเว็บเก่า

ถ้าเว็บเดิมมี structured data ที่ทำให้ขึ้นผลลัพธ์แบบมีรายละเอียดพิเศษ แล้วเว็บใหม่ไม่มี สิ่งที่หายไม่ใช่อันดับโดยตรง แต่คือพื้นที่แสดงผลและโอกาสถูก AI หยิบไปตอบ

**วิธีตรวจ** ใส่ URL ในเครื่องมือ Rich Results Test ของ Google

**วิธีแก้** ติดตั้งใหม่ให้ครบ ดู[คู่มือ Schema Markup ภาษาไทย](https://hashbox.co.th/schema-markup-thai-guide-2026/)ประกอบ

## ลำดับการแก้ที่ได้ผลเร็วที่สุด

ถ้าเจอหลายสาเหตุพร้อมกัน ให้แก้ตามลำดับนี้ เพราะเรียงตามอัตราส่วนระหว่างผลลัพธ์กับแรงที่ใช้

1. ปลดการตั้งค่าห้ามเก็บข้อมูล ถ้าติดอยู่ ใช้เวลาห้านาที เห็นผลภายในไม่กี่วัน
2. ตั้ง redirect ให้หน้าที่เคยมีคนเข้ามากที่สุดก่อน ดูจาก Search Console ว่าหน้าไหนเคยได้คลิกสูงสุด ทำยี่สิบหน้าแรกก่อน แล้วค่อยไล่ที่เหลือ
3. เอาเนื้อหาที่หายกลับมาในหน้าที่เคยติดอันดับดี
4. แก้โครงหัวข้อ
5. ติดตั้ง structured data ใหม่
6. แก้ความเร็ว

หลังแก้แต่ละข้อ ให้ส่งหน้านั้นเข้าเครื่องมือตรวจสอบ URL ใน Search Console เพื่อขอให้เก็บใหม่ ไม่ต้องรอให้ระบบมาเจอเอง

## จะเห็นผลเมื่อไหร่

จากที่เราติดตามงานลักษณะนี้ การกลับมาไม่ได้เกิดพร้อมกันทั้งเว็บ หน้าที่ตั้ง redirect ถูกต้องมักกลับมาก่อน ส่วนหน้าที่ต้องเขียนเนื้อหาเพิ่มใช้เวลานานกว่า

สิ่งที่ควรดูระหว่างรอ ไม่ใช่อันดับอย่างเดียว แต่ให้ดูจำนวนการแสดงผลและจำนวนหน้าที่ถูกจัดทำดัชนีด้วย ถ้าจำนวนหน้าที่ถูกจัดทำดัชนีเริ่มกลับขึ้น แปลว่ากำลังไปถูกทาง แม้อันดับยังไม่ขยับก็ตาม

อีกเรื่องที่ควรรู้เพื่อไม่ให้ตกใจซ้ำ คือหน้าที่เพิ่งกลับเข้าระบบมักมีอันดับต่ำกว่าเดิมช่วงแรกก่อนไต่ขึ้น พฤติกรรมนี้เห็นได้จากข้อมูล Search Console ของเว็บเราเองช่วงมีนาคมถึงมิถุนายน 2026 หลังบทความชุดใหม่ถูกจัดทำดัชนีราวกลางเดือนพฤษภาคม จำนวนการแสดงผลเพิ่มจากวันละไม่ถึงสิบขึ้นเป็น 25 ถึง 43 ขณะที่อันดับเฉลี่ยตกจากช่วงสี่ถึงแปดไปอยู่ที่ 40 ถึง 80 นั่นคือหน้าเริ่มปรากฏในคำค้นที่กว้างขึ้นซึ่งมีคู่แข่งมากกว่า ไม่ใช่การถูกลงโทษ

## ป้องกันสำหรับครั้งหน้า

เก็บสี่อย่างนี้ไว้ก่อนเริ่มย้ายเว็บทุกครั้ง

- ส่งออกรายการ URL ทั้งหมดของเว็บเดิม พร้อมจำนวนคลิกของแต่ละหน้าจาก Search Console
- บันทึกภาพหน้าจอของรายงานผลการค้นหาย้อนหลังสามเดือน ใช้เป็นเส้นฐานเทียบ
- เก็บสำเนาเนื้อหาของหน้าที่ได้คลิกสูงสุดยี่สิบหน้า
- ทำตารางจับคู่ URL เดิมกับ URL ใหม่ให้ครบทุกหน้า ก่อนวันเปิดใช้จริง ไม่ใช่หลัง

ตารางจับคู่ URL คือเอกสารที่สำคัญที่สุดในการย้ายเว็บ และเป็นสิ่งที่ควรระบุในใบเสนอราคาว่าใครเป็นคนทำ รายละเอียดเรื่องการวางขอบเขตงานก่อนจ้าง อยู่ในบทความเรื่อง[เตรียมอะไรบ้างก่อนทำเว็บบริษัทใหม่](https://hashbox.co.th/company-website-ai-ready-2026/)

## คำถามที่พบบ่อย

**ย้ายเว็บโดยไม่เสียอันดับเลยเป็นไปได้ไหม**
เป็นไปได้ถ้า URL ไม่เปลี่ยน เนื้อหายังครบ และความเร็วไม่แย่ลง กรณีเปลี่ยน URL ด้วยมักมีช่วงผันผวนสั้น ๆ แม้ทำ redirect ครบแล้ว ซึ่งถือว่าปกติ

**redirect แบบไหนถึงถูกต้อง**
ใช้ 301 ซึ่งหมายถึงย้ายถาวร ไม่ใช่ 302 ที่หมายถึงย้ายชั่วคราว และต้องชี้ไปหน้าที่เนื้อหาตรงกัน ไม่ใช่ชี้รวมไปหน้าแรก

**ผ่านมาหกเดือนแล้วยังไม่กลับ ยังแก้ทันไหม**
ทัน redirect ที่ตั้งย้อนหลังยังทำงาน แม้จะช้ากว่าการตั้งตั้งแต่วันย้าย สิ่งที่ต้องยอมรับคือหน้าที่ถูกถอดออกจากระบบไปนานแล้วต้องเริ่มสะสมใหม่ ไม่ได้กลับมาที่เดิมทันที

**เปลี่ยนแค่ธีม ไม่ได้เปลี่ยน URL ทำไมอันดับยังตก**
มักเป็นสาเหตุที่ 3 ถึง 5 คือเนื้อหาหาย โครงหัวข้อเปลี่ยน หรือเว็บช้าลง ธีมใหม่ที่เน้นภาพมักลดปริมาณข้อความลงโดยที่เจ้าของเว็บไม่ทันสังเกต

**ต้องส่ง sitemap ใหม่ไหม**
ควรส่ง และควรตรวจว่า sitemap มีเฉพาะ URL ใหม่ ไม่ใช่ปนกับ URL เดิมที่ redirect ไปแล้ว

**ควรบอก Google ว่าย้ายเว็บอย่างไร**
ถ้าเปลี่ยนโดเมน ใช้เครื่องมือเปลี่ยนที่อยู่เว็บใน Search Console ถ้าเปลี่ยนเฉพาะโครงสร้าง URL ภายในโดเมนเดิม ไม่มีเครื่องมือแจ้ง ต้องอาศัย redirect กับ sitemap เท่านั้น
