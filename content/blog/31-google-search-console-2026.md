# Google Search Console คืออะไร ใช้ยังไง? คู่มือ 2026 ฉบับใช้จริง

> **คำตอบสั้น:** **Google Search Console (GSC)** คือเครื่องมือ*ฟรี*จาก Google ที่รายงานสถานะเว็บคุณในผลค้นหาโดยตรง: คนเห็นเว็บคุณด้วย**คำค้นอะไร** (impressions) กี่ครั้ง อันดับเฉลี่ยเท่าไหร่ คลิกกี่ครั้ง หน้าไหน**ถูก index** หน้าไหนมีปัญหา และเว็บโดนลงโทษ (manual action) หรือไม่ — ต่างจาก Google Analytics ตรงที่ GA บอกว่าคนทำอะไร*หลังเข้าเว็บ* ส่วน GSC บอกทุกอย่าง*ก่อนคลิก* — ใครทำเว็บแล้วยังไม่เปิด GSC เท่ากับทำ SEO แบบไม่มีมาตรวัด: เปิดฟรีที่ **search.google.com/search-console** ใช้เวลา 10 นาที

เราใช้ GSC เป็นมาตรวัดหลักของงานลูกค้าทุกราย — กระทั่ง[การันตี "ไม่โต ไม่จ่าย"](/services/seo/guarantee-terms/)ของเราก็เขียนให้ตัดสินด้วยตัวเลขใน GSC *ของลูกค้าเอง* เพราะมันคือแหล่งเดียวที่ไม่มีใครแต่งตัวเลขได้ — คู่มือนี้คือวิธีใช้แบบเดียวกับที่เราใช้ทำงานจริง

## GSC ต่างจาก Google Analytics ยังไง {#vs-ga}

| | Google Search Console | Google Analytics (GA4) |
|---|---|---|
| ตอบคำถาม | คนเจอเราใน Google ด้วยคำอะไร อันดับเท่าไหร่ | คนเข้าเว็บแล้วทำอะไรต่อ |
| ข้อมูลหลัก | คำค้น, impressions, คลิก, อันดับ, การ index | session, พฤติกรรม, conversion |
| มุมเวลา | ก่อนคลิก | หลังคลิก |
| ใช้คู่กัน | วัดว่า "ถูกเห็น" | วัดว่า "ขายได้" |

สองตัวนี้ไม่แทนกัน — งาน SEO เริ่มที่ GSC เสมอเพราะปัญหาส่วนใหญ่ (ไม่ถูก index, อันดับต่ำ, คำผิดหน้า) มองไม่เห็นจาก GA

## วิธีติดตั้งทีละขั้น {#setup}

1. ไปที่ **search.google.com/search-console** ล็อกอินบัญชี Google
2. เลือกประเภท property: **Domain** (แนะนำ — ครอบทุก subdomain/โปรโตคอล แต่ต้องยืนยันผ่าน DNS) หรือ **URL prefix** (ง่ายกว่า — ยืนยันผ่านไฟล์/tag ได้ แต่ครอบเฉพาะ URL ที่ระบุ)
3. **ยืนยันความเป็นเจ้าของ** — Domain: เพิ่ม TXT record ใน DNS ตามที่ระบบให้ · URL prefix: อัปโหลดไฟล์ HTML, ใส่ meta tag, หรือผูกผ่าน Analytics/Tag Manager ที่มีอยู่
4. **ส่ง sitemap** — เมนู Sitemaps ใส่ URL เช่น `https://เว็บคุณ/sitemap_index.xml` (WordPress ที่ลงปลั๊กอิน SEO มีให้อัตโนมัติ)
5. รอข้อมูล 2–3 วันแรก — ข้อมูลย้อนหลังจะเริ่มไหลเข้า (GSC เก็บให้สูงสุด 16 เดือน)

ทริคที่คนพลาด: ยืนยันแบบ Domain ตั้งแต่แรกคุ้มกว่า — เว็บที่มีทั้ง www/ไม่มี www, http/https จะเห็นข้อมูลรวมในที่เดียว

## 6 รายงานที่ต้องดูจริง {#reports}

1. **Performance (ผลการปฏิบัติงาน)** — หัวใจของทั้งเครื่องมือ: คำค้น × หน้า × อันดับ × คลิก กรองตามช่วงเวลา/ประเทศ/อุปกรณ์ได้ — คำที่อยู่อันดับ 8–30 ในรายงานนี้คือรายการงานที่คุ้มสุดของคุณ
2. **Indexing → Pages (การจัดทำดัชนี)** — หน้าไหน index แล้ว หน้าไหนไม่ พร้อมเหตุผล (พบแล้วยังไม่ index / ถูก noindex / ซ้ำ canonical) — เว็บที่หน้าใหม่ไม่ติดสักที คำตอบอยู่ตรงนี้
3. **URL Inspection (ตรวจสอบ URL)** — เช็ครายหน้า: index หรือยัง, Google เห็นหน้าเป็นยังไง, และปุ่ม **Request Indexing** สำหรับหน้าใหม่/เพิ่งแก้ (มีโควต้าราว 10 ครั้ง/วันแบบ rolling — ใช้กับหน้าสำคัญเท่านั้น)
4. **Sitemaps** — Google อ่าน sitemap ล่าสุดเมื่อไหร่ เห็นกี่ URL — ถ้าจำนวนไม่ตรงกับหน้าที่มีจริง แปลว่า sitemap ตกหล่นหรือ cache ค้าง
5. **Core Web Vitals** — ความเร็ว/ความนิ่งของหน้าจากข้อมูลผู้ใช้จริง แยกมือถือ/เดสก์ท็อป — หน้ากลุ่ม "ต้องปรับปรุง" คือรายการงาน technical (พื้นฐานอ่านที่ [Core Web Vitals คืออะไร](/core-web-vitals-thai-guide-2026/))
6. **Manual Actions + Security** — ต้องเป็น "ไม่พบปัญหา" เสมอ ถ้ามีอะไรโผล่ = เรื่องด่วนที่สุดในเว็บคุณ (สาเหตุพบบ่อยคือ[เคยทำ SEO สายเทา](/seo-สายเทา-vs-สายขาว-2026/))

## วิธีอ่านค่าเป็นรอบ 28 วัน {#reading}

กติกาที่เราใช้กับลูกค้าจริง — เปิด Performance ตั้งช่วง 28 วัน เทียบกับ 28 วันก่อนหน้า แล้วไล่ 4 คำถาม:

1. **Impressions โตไหม** — ตัวชี้แรกสุดว่า Google เริ่มเอาเราไปแสดง (โตก่อนคลิกเสมอ — เว็บใหม่อย่าเพิ่งวัดที่คลิก)
2. **คำไหน impressions สูงแต่ CTR ต่ำผิดปกติ** — คนเห็นแต่ไม่คลิก → แก้ title/description ให้ตรงกับสิ่งที่คนค้นหา
3. **คำไหนค้างอันดับ 11–30** — ใกล้หน้าแรกแล้ว → เสริมเนื้อหา + ลิงก์ภายในเข้าหน้านั้น คุ้มกว่าเขียนเรื่องใหม่
4. **หน้าไหน 0 impressions เกิน 6 สัปดาห์** — เช็ค index ก่อน แล้วเช็คว่าเรื่องซ้ำกับหน้าอื่นของตัวเองไหม

จดทุกการแก้พร้อมวันที่ — รอบถัดไปถึงจะรู้ว่าอะไรได้ผล (workflow เต็มสำหรับมือใหม่อยู่ที่[มือใหม่ทำ SEO ควรทำอย่างไร](/seo-มือใหม่-2026/))

## ใช้ GSC ตัดสินใจแก้เว็บยังไง {#actions}

ตัวอย่างจริงจากงานเรา — สามสถานการณ์ที่เจอบ่อยสุดและทางแก้:

- **หน้าใหม่ไม่ index หลายสัปดาห์** → URL Inspection ดูสถานะ: "Google ไม่รู้จัก URL" = ยังไม่ถูก crawl → เช็คว่าอยู่ใน sitemap + มีลิงก์ภายในเข้าไหม แล้วค่อย Request Indexing · "พบแล้วยังไม่ index" = Google เห็นแต่ยังไม่จัดคิว → มักเป็นเรื่องคุณภาพ/ความซ้ำของเนื้อหา
- **อันดับดีแต่ยอดขายไม่มา** → Performance กรองดูคำ: ถ้าคำที่ติดเป็น informational ล้วน แปลว่าขาดหน้า commercial — ปัญหาอยู่ที่แผนคีย์เวิร์ด ไม่ใช่อันดับ
- **Impressions ดิ่งกะทันหัน** → เช็คตามลำดับ: Manual Actions → Indexing (หน้าหลุด index เยอะไหม) → ข่าว core update ของ Google ช่วงนั้น — อย่าเพิ่งรื้อเว็บก่อนรู้สาเหตุ

ถ้าเปิดรายงานแล้วเจอปัญหาที่แก้เองไม่ถูก — [ขอ SEO Audit ฟรี](/services/seo/) เราไล่ให้ทั้งเว็บพร้อมลำดับความสำคัญ

## ข้อจำกัดที่ต้องรู้ {#limits}

- **ข้อมูลคำค้นถูกกรองบางส่วน** — คำที่มีปริมาณน้อยมากถูกซ่อนเพื่อความเป็นส่วนตัว ยอดรวมรายคำจึงน้อยกว่ายอดรวมจริง
- **อันดับเป็น "ค่าเฉลี่ย"** — รวมทุกตำแหน่งที่เคยแสดง (รวม local pack, รูป) — อันดับ 13 ใน GSC ไม่ได้แปลว่าอยู่หน้า 2 เสมอ
- **ไม่บอกข้อมูลคู่แข่ง** — GSC เห็นแค่เว็บตัวเอง การเทียบกับตลาดต้องใช้เครื่องมืออื่นประกอบ
- **AI Overviews ยังไม่แยกรายงาน** — คลิก/impressions จาก AI Overview ถูกนับรวมกับผลปกติ ยังแยกดูไม่ได้ ([รายละเอียดเรื่องนี้](/google-ai-overview-thailand-2026/))

## FAQ {#faq}

### Google Search Console ฟรีไหม

ฟรี 100% ทุกฟีเจอร์ ไม่มีแผนเสียเงิน — สิ่งเดียวที่ต้องมีคือบัญชี Google และสิทธิ์ยืนยันความเป็นเจ้าของเว็บ (เข้าถึง DNS หรือแก้ไฟล์บนเว็บได้)

### GSC กับ Google Analytics ต้องใช้ทั้งคู่ไหม

ควรทั้งคู่ — GSC วัด "ถูกค้นเจอ" GA วัด "เข้ามาแล้วทำอะไร" เว็บที่เน้น SEO ให้เปิด GSC ก่อนเพราะข้อมูลเริ่มเก็บตั้งแต่วันยืนยัน ย้อนหลังไม่ได้

### Request Indexing กดแล้วติดเลยไหม

ไม่ — มันแค่ส่งเข้าคิว crawl เร็วขึ้น การจะ index หรือไม่ยังขึ้นกับคุณภาพหน้า และมีโควต้าราว 10 URL/วันแบบ rolling 24 ชม. — หน้าใหม่ที่อยู่ใน sitemap และมีลิงก์ภายในดี ๆ ส่วนใหญ่ถูกเก็บเองโดยไม่ต้องกด

### ทำไมอันดับใน GSC ไม่ตรงกับที่ค้นเอง

เพราะผลค้นหาถูกปรับตามตำแหน่ง อุปกรณ์ ประวัติ และ GSC รายงานเป็นค่าเฉลี่ยของทุกการแสดงผล — ใช้ GSC ดูแนวโน้ม อย่าใช้จับผิดรายวัน และการค้นเองบ่อย ๆ ทำให้ผลที่เห็นเพี้ยนจากคนทั่วไป

### ควรเปิด GSC ให้เอเจนซีที่จ้างไหม

ควร — ให้สิทธิ์ระดับ "Full" ได้โดย**คุณยังเป็น Owner** (อย่าโอน ownership เด็ดขาด) เอเจนซีที่ดีจะขอเข้าถึงตั้งแต่วันแรกเพราะทำงานโดยไม่มี GSC ไม่ได้ และ[การวัดผล/การันตีที่ตรวจสอบได้](/ค่าจ้าง-seo-2026/)ควรอิงตัวเลขใน property ของคุณเอง
