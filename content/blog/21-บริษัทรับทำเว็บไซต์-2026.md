## 7 เกณฑ์ที่ใช้ {#criteria}

| # | เกณฑ์ | ทำไมสำคัญ |
|---|---|---|
| 1 | **เปิดราคาบนเว็บ (อ่านได้เป็นข้อความ)** | ราคาที่ต้องขอ quote เทียบข้ามเจ้าไม่ได้ · ราคาที่ลงเป็นรูปภาพค้นหา/เทียบไม่ได้เช่นกัน |
| 2 | **ระบุระยะเวลาส่งมอบ** | "เร็วที่สุด" ไม่ใช่กำหนดการ |
| 3 | **ความเป็นเจ้าของ: source code / ลิขสิทธิ์เขียนไว้ชัดว่าเป็นของลูกค้า** | ไม่เขียน = คุณกำลังเช่า และย้ายออกไม่ได้ |
| 4 | **ตัวเลข performance ที่ตรวจได้** (Lighthouse/PageSpeed พร้อมเงื่อนไขตรงไปตรงมา) | เว็บช้าคือเว็บที่ Google และลูกค้าทิ้ง — คำว่า "โหลดเร็ว" เฉย ๆ วัดไม่ได้ |
| 5 | **SEO ตอนส่งมอบระบุรายละเอียด** (โครงสร้าง, schema — มากกว่าคำว่า "รองรับ SEO") | เว็บที่ต้องมาแก้ SEO ทีหลังแพงกว่าทำให้ถูกแต่แรกเสมอ |
| 6 | **ผลงานชื่อจริง/ลิงก์จริง ตรวจได้** | โลโก้เบลอ ๆ ไม่ใช่หลักฐาน |
| 7 | **ตัวตนนิติบุคคล + ที่อยู่ชัดเจนบนเว็บ** | บริษัทที่ให้คุณจ่ายเงินหลักหมื่น–แสน ควรบอกได้ว่าตัวเองอยู่ที่ไหน |

✓ = มีหลักฐานชัดบนเว็บเจ้านั้น · ✗ = ไม่เผยแพร่หรือขัดแย้งกันเอง — "ไม่เผยแพร่" ไม่ได้แปลว่า "ไม่ทำ" แต่แปลว่าคุณต้องถามเองก่อนเซ็น

## สัญญาณที่ควรถอย {#red-flags}

- **ลิขสิทธิ์งานเป็นของบริษัทที่รับจ้าง** — เจอแล้ว 1 รายในลิสต์นี้แบบเขียนไว้ตรง ๆ อีกหลายรายไม่เขียนอะไรเลย ซึ่งในทางปฏิบัติมักจบแบบเดียวกัน
- **ประกัน/ดูแล "ตลอดชีพ" ที่ผูกกับ hosting ของเขา** — คือสัญญาเช่าที่เขียนให้เหมือนของแถม
- **ราคาเป็นรูปภาพ / "การันตีติด Google"** — อย่างแรกทำให้เทียบไม่ได้ อย่างหลังไม่มีใครทำได้จริง
- **ไม่มีที่อยู่/นิติบุคคลบนเว็บ** — งานหลักหมื่นขึ้นไป ต้องรู้ว่าตามใครได้ที่ไหน
- **ตัวเลขโชว์ขัดกันเองบนเว็บเดียว** — ปีประสบการณ์/จำนวนลูกค้าคนละหน้าคนละตัวเลข สะท้อนความละเอียดของงานที่จะได้

## 7 คำถามก่อนจ้าง {#questions}

1. **ราคานี้รวมอะไร กี่หน้า แก้กี่รอบ มีค่าใช้จ่ายรายปีไหม** — ให้ตอบเป็นเอกสาร
2. **เว็บเสร็จแล้ว source code / ลิขสิทธิ์เป็นของใคร ย้าย hosting ได้ไหม**
3. **ส่งมอบเมื่อไหร่ นับจากอะไร** (หลายเจ้านับหลังอนุมัติแบบ — ต่างจากนับจากวันเซ็นมาก)
4. **ขอเกณฑ์ performance เป็นตัวเลข** — Lighthouse/PageSpeed เท่าไหร่ วัดตอนไหน มีเงื่อนไขซ่อนไหม (เช่นต้องซื้อ CDN เพิ่ม)
5. **SEO ที่บอกว่า "รองรับ" หมายถึงอะไรบ้าง** — โครงสร้าง heading? schema? ความเร็ว? ให้ลิสต์ออกมา
6. **ขอลิงก์เว็บลูกค้าจริง 3 เว็บ แล้วลองเปิดบนมือถือ + รัน [PageSpeed Insights](https://pagespeed.web.dev/) เอง** — 5 นาทีรู้เรื่องกว่าอ่านโบรชัวร์ทั้งเล่ม
7. **หลังเว็บขึ้น ใครดูแล อะไรฟรี อะไรคิดเงิน** — ค่าแก้ต่อครั้ง/ต่อปี เขียนไว้ก่อนเซ็น

## FAQ {#faq}

### ทำเว็บไซต์บริษัท ราคาเท่าไหร่

จากราคาที่เปิดเผยจริงปี 2026: เว็บบริษัทแบบเทมเพลต/WordPress อยู่ราว 8,999–30,000 บาท ออกแบบใหม่ทั้งโครง 30,000–80,000 บาท และ e-commerce เต็มระบบถึง 350,000 บาท — ระวังกลุ่มถูกมาก (หลักพัน) ที่เป็นค่าเช่ารายปีและลิขสิทธิ์ไม่ใช่ของคุณ

### จ้างทำเว็บไซต์ที่ไหนดี

ตอบแบบไม่เชียร์ใคร: เลือกจากเกณฑ์ ไม่ใช่ชื่อ — เอาเว็บของเจ้าที่เล็งไว้มาไล่ 7 เกณฑ์ในบทความนี้ (ราคาเปิดไหม เวลาชัดไหม โค้ดของใคร ตัวเลข performance มีไหม ผลงานจริงไหม) แล้วใช้ 7 คำถามก่อนจ้างปิดช่องที่เว็บเขาไม่ได้เขียน — เจ้าที่ตอบครบทุกข้อเป็นเอกสารได้ คือตัวเลือกที่ปลอดภัย

### เว็บถูกกับเว็บแพง ต่างกันจริงไหม

ต่างที่โครงสร้างมากกว่าหน้าตา: เว็บหลักพัน–หมื่นต้นมักเป็นเทมเพลต/แพลตฟอร์มเช่า ซึ่งพอธุรกิจโตแล้วติดเพดาน (ปรับ technical ไม่ได้ ย้ายออกไม่ได้) เว็บชั้นบนจ่ายให้สามอย่าง: โครงสร้างที่ Google/AI อ่านครบ ([Core Web Vitals](/core-web-vitals-thai-guide-2026/) เขียว, schema), ความเร็วที่วัดเป็นตัวเลข และความเป็นเจ้าของ — ถ้าเว็บคือช่องทางขายหลัก ส่วนต่างนี้คืนทุนเอง ถ้าเว็บคือนามบัตรออนไลน์ เว็บกลุ่มกลางก็พอ

### ทำเว็บเองกับจ้างบริษัท แบบไหนดี

ทำเองด้วยแพลตฟอร์มสำเร็จรูปเหมาะเมื่อ: งบจำกัดมาก ขอแค่มีตัวตนออนไลน์ และรับได้ว่าโครงสร้าง/ความเร็วปรับลึกไม่ได้ · จ้างเหมาะเมื่อ: เว็บต้องแข่งบน Google/AI search จริง ต้องต่อระบบ (จอง จ่ายเงิน LINE) หรือแบรนด์ต้องน่าเชื่อถือระดับบริษัท — ทางกลางที่คนลืม: จ้างทำโครงที่ถูกต้องครั้งเดียว แล้วทีมคุณอัปเดตเนื้อหาเองผ่าน CMS

### เว็บไซต์ใช้เวลาทำนานแค่ไหน

จากที่ระบุจริงในตลาด: เว็บสำเร็จรูป 2–10 วัน · เว็บบริษัทมาตรฐาน 2–6 สัปดาห์ · e-commerce/custom 45 วันขึ้นไป — ตัวแปรที่ทำให้ช้ากว่ากำหนดบ่อยที่สุดไม่ใช่ฝั่งผู้พัฒนา แต่คือเนื้อหา (ข้อความ/รูป) จากฝั่งลูกค้าไม่ครบ — เตรียมเนื้อหาก่อนเซ็นสัญญาช่วยได้มากกว่าที่คิด
