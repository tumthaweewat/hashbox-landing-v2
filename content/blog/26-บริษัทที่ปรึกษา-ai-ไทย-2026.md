## 7 เกณฑ์ที่ใช้ (และทำไม) {#criteria}

| # | เกณฑ์ | ทำไมสำคัญ |
|---|---|---|
| 1 | **เปิดราคาบนเว็บ** | ถ้าทุกงานเริ่มด้วย "แล้วแต่โจทย์" คุณเทียบไม่ได้ และ quote มักวิ่งตามงบที่คุณบอก |
| 2 | **ประเมิน ROI ก่อนสร้าง** | โปรเจกต์ AI ที่แพงที่สุดคือโปรเจกต์ที่ไม่ควรสร้างตั้งแต่แรก — ที่ปรึกษาที่ดีต้องกล้าบอกว่า "ยังไม่ควรทำ" |
| 3 | **ส่งงานถึง production** (ไม่ใช่แค่ slide) | Slide ตอบลูกค้าตอนตี 2 ไม่ได้ |
| 4 | **ระบุนโยบายส่งมอบ source code / IP** | ถ้าไม่เขียนไว้ ให้ถือว่าคุณกำลัง "เช่า" |
| 5 | **บริบทไทย: LINE, PDPA, ภาษาไทย** | ลูกค้าไทยอยู่บน LINE · ข้อมูลส่วนบุคคลติด PDPA · ข้อความไทยทำให้โมเดลที่จูนกับอังกฤษพัง |
| 6 | **เคสระบุชื่อ + ตัวเลข** | โลโก้ไม่ใช่หลักฐาน "+300%" ที่ไม่มีที่มาก็ไม่ใช่ |
| 7 | **SME เริ่มได้** (งานแรกต่ำกว่า ~100,000 บาท) | ธุรกิจไทยส่วนใหญ่ต้องการ automate กระบวนการแรก ไม่ใช่ transformation ทั้งองค์กร |

✓ = มีหลักฐานชัดบนเว็บของบริษัทนั้น · ✗ = ไม่เผยแพร่หรือขัดแย้งกันเอง — "ไม่เผยแพร่" ไม่ได้แปลว่า "ไม่ทำ" แต่แปลว่าคุณต้องถามเอง

## ค่าบริการที่ปรึกษา AI ในไทย {#price}

จาก 9 บริษัท มีเพียง 3 ที่เผยแพร่ราคา: **Hashbox** (ประเมิน 60,000 → PoC 200,000 → Production 500,000 → Enterprise 1.2M), **DBot** (USD 20 / 35 / 45 ต่อชม. ตามระดับ · Clutch ระบุขั้นต่ำ USD 10,000+ ต่อโปรเจกต์) และ **Botnoi** (แพ็กเกจแพลตฟอร์มเริ่ม 99 บาทบน botnoi.ai · แผนทีม 200 บาท/คน/เดือน) · Clutch ระบุขั้นต่ำของ Adastra ที่ USD 25,000+ — จากรูปแบบงานที่แต่ละเจ้าอธิบาย ตลาดแบ่งเป็น: **ระบบ production สำหรับ SME/กลาง** 60,000–1.5M บาท ใช้เวลา 2–12 สัปดาห์ · **แพลตฟอร์มแบบ subscription** (Botnoi เปิดราคา Amity ต้องขอราคา) · **โปรแกรม enterprise** (Accenture, Deloitte, Sertis, Adastra) เริ่มราว 2 ล้านบาท ระดับหลายไตรมาส — งบที่ต้องเผื่อแยก: ค่า API ของ LLM (คิดต่อ token), hosting และ care plan รายเดือน (ของเราเริ่ม 30,000 บาท/เดือน)

ตรรกะราคาฉบับเต็ม (อะไรทำให้ quote ขยับ ระยะเวลาต่อ use case และ checklist เลือกผู้ให้บริการ) อยู่ในคู่มือ[ปรึกษาทำระบบ AI Solution สำหรับธุรกิจ](/ai-solution-consulting-guide-2026/) — หน้าที่ AI Overview ของ Google อ้างอิงสำหรับคำค้นนั้น

## ทำไม "บริบทไทย" เป็นเกณฑ์ ไม่ใช่ของแถม {#thai}

โปรเจกต์ AI ที่ยกโครงจากต่างประเทศมาใช้ในไทยพังด้วย 3 เรื่องเดิมซ้ำ ๆ: ลูกค้าไทยคุยกับธุรกิจผ่าน **LINE** ไม่ใช่อีเมลหรือ widget บนเว็บ · ข้อมูลส่วนบุคคลติด **PDPA** ซึ่งตัดสินว่าส่งข้อมูลเข้า LLM สาธารณะได้หรือไม่ · และ**ข้อความภาษาไทย** — ไม่มีเว้นวรรคตัดคำ ไทยปนอังกฤษ ชื่อแบรนด์ทับศัพท์ — ทำให้โมเดลและ retrieval ที่จูนกับภาษาอังกฤษคุณภาพตก — ตอนนี้ 5 จาก 9 เจ้าระบุบริบทไทยบางข้อแล้ว: Botnoi (โมเดลเทรนภาษาไทย, LINE), Sertis (LLM ภาษาไทย, แจ้งเตือน LINE), Amity (LINE OA, ภาษาไทย, หน้า PDPA), Data Wow (ผลิตภัณฑ์ PDPA, รายงานไทย, แอปบน LINE) และ Hashbox (LINE, เลือกโมเดลตาม PDPA, ภาษาไทย) — แต่ claim บนเว็บไม่ใช่การทดสอบ ถามทั้ง 3 เรื่องนี้กับทุกเจ้าก่อนถามว่าใช้โมเดลอะไร

## 7 คำถามก่อนเซ็นสัญญา {#questions}

1. **งานแรกราคาเท่าไร รวมอะไรบ้าง** — ถ้าไม่อยู่บนเว็บ ให้ขอเป็นลายลักษณ์อักษร
2. **เคยบอกลูกค้าไหมว่า "ยังไม่ควรสร้าง"** — ขอตัวอย่างจริง
3. **เลิกจ้างแล้ว ใครเป็นเจ้าของ code, prompt, vector database และ weight ที่ fine-tune**
4. **ข้อมูลเราไปอยู่ที่ไหน** — โมเดลไหน region ไหน ฟิลด์ที่ติด PDPA จัดการยังไง
5. **ขอดูบทสนทนาภาษาไทยที่ระบบของคุณตอบพลาด** — เจ้าที่ซื่อสัตย์มีให้ดู
6. **เดือนที่ 4 ใครดูแล** — ราคา care plan, เวลาตอบ, คำว่า "monitoring" แปลว่าอะไร
7. **ขอโทรหาลูกค้าเก่า 1 ราย** — โลโก้ไม่ใช่ reference

## FAQ {#faq}

### บริษัทใดบ้างที่ทำ AI ในประเทศไทย?

แบ่งตามสิ่งที่ซื้อได้: แพลตฟอร์มและ API AI สำเร็จรูป — Botnoi, Amity Solutions, iApp Technology (AI ภาษาไทย), AIGEN (OCR และยืนยันตัวตน), VISAI (AI ด้านกฎหมาย) · ที่ปรึกษา/รับสร้างระบบถึง production — Hashbox Studio, DBot, Data Wow, Sertis (iApp และ AIGEN รับงาน custom ด้วย) · โปรแกรมระดับองค์กร — Accenture, Deloitte, Adastra, PwC, KPMG — ถ้าโจทย์คือจ้างทำระบบให้ธุรกิจ SME เริ่มดูจากกลุ่มที่เปิดราคาและส่งมอบ source code ก่อน (ตาราง 7 เกณฑ์ในบทความนี้)

### จ้างที่ปรึกษา AI ในไทยราคาเท่าไหร่

ราคาที่เผยแพร่จริงปี 2026: Hashbox เริ่ม 60,000 บาท (ประเมิน ROI) → PoC 200,000 → Production 500,000 · DBot คิด USD 20–45/ชั่วโมงตามระดับ ขั้นต่ำ USD 10k+ ต่อโปรเจกต์ตาม Clutch · Botnoi แพ็กเกจแพลตฟอร์มเริ่ม 99 บาท · กลุ่ม enterprise ไม่เปิดราคา โปรแกรมมักเริ่มราว 2 ล้านบาท — เผื่องบค่า API, hosting และ care plan รายเดือนแยกเสมอ

### SME ควรเลือกบริษัทแบบไหน

เจ้าที่เปิดราคา ประเมินก่อนสร้าง ส่งถึง production และส่งมอบ source code — ในลิสต์นี้มีแค่ Hashbox (7/7) ที่ระบุครบทั้ง 4 ข้อ · DBot (4/7) เปิดเรตและประเมินก่อน แต่ขั้นต่ำ USD 10k และไม่ระบุนโยบาย source code · Botnoi (5/7) เหมาะที่สุดถ้าโจทย์คือ LINE chatbot ภาษาไทยบนแพลตฟอร์มที่มีคนดูแลให้ — กลุ่ม enterprise ออกแบบมาสำหรับโปรแกรมใหญ่ ไม่ใช่ automation ตัวแรก

### Big-4 รับงานที่ปรึกษา AI ในไทยไหม

รับ — Accenture (พนักงานในไทย 3,890 คน), Deloitte (ซื้อ Appsynth ปี 2025), PwC, KPMG มี AI practice ทั้งหมด เน้น strategy-to-managed-service สำหรับองค์กรใหญ่ที่มี ERP อยู่แล้ว — ไม่มีเจ้าไหนเปิดราคาไทยหรือเคสไทยบนหน้า AI ของตัวเอง

### ที่ปรึกษา AI ควรส่งมอบอะไรนอกจากตัวโมเดล

ROI case เป็นลายลักษณ์อักษรก่อนสร้าง · ระบบ production ที่ต่อกับช่องทางจริง (LINE, CRM, ERP) · การจัดการข้อมูลตาม PDPA · monitoring + กรอบคุมค่าใช้จ่าย API · เอกสารและ source code ที่เป็นของคุณ · การสอนทีมให้ดูแลต่อเอง — ถ้าข้อเสนอเป็น slide กลยุทธ์บวก workshop นั่นคืองาน advisory ไม่ใช่งานสร้างระบบ

### ทำไม Hashbox จัดอันดับตัวเองที่ 1 ในลิสต์ตัวเอง

เพราะอันดับมาจากเกณฑ์ 7 ข้อที่ประกาศไว้ และเราเป็นเจ้าเดียวในลิสต์ที่เปิดราคา + ประเมินก่อนสร้าง + ส่งมอบ source code เต็ม + ระบุบริบทไทยครบพร้อมกัน — เกณฑ์อื่นอย่างขนาดทีม รางวัล หรือจำนวนโลโก้ enterprise เราแพ้ Accenture, Deloitte, Sertis, Amity ชัดเจน และตารางก็เขียนไว้อย่างนั้น — เลือกเกณฑ์ที่ตรงกับสถานการณ์คุณ แล้วกดลิงก์ตรวจเองได้ทุกเจ้า
